# Rohini Lorry Transport - Replaceable Images Directory

Place your actual image files here in `public/images/` using these exact file names:

| File Name | Description | Where It Appears |
|-----------|-------------|------------------|
| `rohini-logo.png` | Company Emblem / Logo | Header, Mobile Menu & Footer |
| `hero-truck.jpg` | Decorated Indian Lorry Photo | Top Hero Banner on Home Page |
| `india-routes.png` | All India Freight Routes Map | All India Transport Network Section |
| `owner-photo.png` | Photo of N. Babu Reddy | About Us Section |

## How to replace in VS Code:
1. Open this project in VS Code.
2. In the left file explorer, open `public` -> `images`.
3. Drag & drop your real photos here, keeping the exact names above (`rohini-logo.png`, `hero-truck.jpg`, `owner-photo.png`).
4. Save and run `npm run dev`. The site will display your actual photos instantly!
